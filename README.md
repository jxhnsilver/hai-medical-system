# Hai.MedicalSystem (МИС) — Тестовое задание для Хаймедтех

Мини-проект медицинской информационной системы (МИС), разработанный в рамках тестового задания для компании Хаймедтех. Приложение реализует базовый функционал учета пациентов, врачей и заболеваний с использованием технологий экосистемы .NET.

## Технологии
- .NET 10
- .NET Aspire (оркестрация)
- ASP.NET Core Web API
- Entity Framework Core + PostgreSQL 18
- Swagger (документация API)
- Встроенное логирование и глобальная обработка исключений

## Реализовано по заданию
### Проектирование схемы БД
Разработана структура базы данных на основе трех ключевых сущностей по ТЗ: **Пациент**, **Доктор**, **Болезнь**. Продуманы поля для потенциальной бизнес-логики МИС (полис ОМС, даты рождения, статусы врачей, коды МКБ). Реализована связь Many-to-Many между пациентами и болезнями через промежуточную таблицу. Управление схемой осуществляется через механизм EF Core Migrations.

### API Эндпоинты
- `GET /api/patients` — список всех пациентов
- `GET /api/patients/{id}` — информация о конкретном пациенте
- `GET /api/doctors/grouped-by-specialization` — врачи, сгруппированные по специализациям
- `GET /api/diseases` — общий справочник болезней

### Обработка ошибок и логирование
- **Глобальный `IExceptionHandler`:** Перехватывает любые сбои приложения
- **Логирование 500 ошибок:** Автоматически пишет в лог детальный stack trace при критических серверных сбоях
- **Debug в сервисах:** Логирует пошаговое выполнение бизнес-логики и состояние объектов для удобной отладки

### Как запустить
Требуется установленный Docker Desktop и .NET 10 SDK.
1. Перейдите в папку решения и запустите AppHost:
```bash
dotnet run --project src/Hai.MedicalSystem.AppHost
```
2. Дождитесь запуска. Aspire автоматически поднимет PostgreSQL в докер контейнере, запустит локальный API проект и применит миграции.
3. Swagger UI доступен по одному из адресов:
  - **Локальный запуск**: `https://localhost:7110/swagger` (или `http://localhost:5250/swagger`)
  - **Через Docker-контейнер**: `http://localhost:<DOCKER_PORT>/swagger` (порт пробрасывается динамически, точное значение можно посмотреть в докере)
4. Для загрузки тестовых данных откройте PgAdmin в Dashboard Aspire, подключитесь к базе `medical-db` и выполните SQL-скрипт `seed-data.sql`.
